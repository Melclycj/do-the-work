## 3.5 The guard's first live firing blocked this round's own candidate — the rename interaction

The candidate commit itself was the new guard's first live subject, and the guard blocked it:
a `git mv` rename makes `git diff --cached -U0 -- <new-path>` render the member's **whole
standing text as added lines** — the pathspec filters the old path out of the diff, which
breaks the rename pairing — so the five `E2`-frozen supersession tokens of §2, standing stock
the clause says the guard never re-scans, were re-scanned and flagged:

```
pre-commit BLOCKED: newly added instruction text names a repository path that does not resolve:
  contract/…-supersession-1.md: `ResearchSystem/migration/…/W2/W2-design.md` …
  contract/…-supersession-1.md: `ResearchSystem/migration/…/W2/W2-record.md` …
  contract/…-supersession-2.md: `assurance/runs/` …
  contract/…-supersession-2.md: `templates/run-v2/` …
  contract/…-supersession-2.md: `ResearchSystem/migration/document-work-assurance-v3/` …
```

The fix (a pre-submission correction — no FULL had occurred, `E9`) is one **un-pathspec'd**
`git diff --cached -M -U0` parsed per post-image path (`added_lines_by_path`), so a staged
rename pairs and contributes no added lines. Two tests pin the class both ways: a rename into
a member path with bad standing text passes (negative), a bad line added on top of a rename
still blocks (must-fire). Three further mutation results, sha256-checked restores throughout
(v2 snapshot `198e9424272ac2b35d8cdb44c135043bc7d821fde575960883b43a07167f0a4a`):

- **`-M` dropped** from the un-pathspec'd form: the rename test **stayed green** — porcelain
  `git diff` detects renames by default (`diff.renames` defaults true), so `-M` is not what
  the test binds; it stays in the command as an explicit pin against a machine configured
  with `diff.renames=false`, and that residual dependence is recorded here rather than
  claimed as tested.
- **Pathspec limitation restored** (the original defect shape): the rename test went red —
  `1 failed, 1 passed` — so the test binds the actual fix.
- Battery after the correction: **738 passed** (736 + the two rename tests).
