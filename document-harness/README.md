# Document Work Assurance Harness (v3)

A local, instruction-driven harness that makes silent omission, unsupported completion claims,
wrong review subjects and unbounded repair loops visible before a user accepts document changes.
Document work only (Markdown / JSON / YAML / plans / design notes / metadata) — no coding
orchestration, no enforcement claims, no external side effects.

Node state deliberately lives elsewhere: **each node's administrative record is the sole
status owner** — this file claims no node state, because a file that does not claim node
state cannot go stale about it.
