## 4. 这条 lint 上线第一次就拦了自己

首次在真实暂存区跑，它**拦下了本轮自己的提交**，两条：`.git/hooks/` 与 `.harness/review-pending.json`
——都是 README 里合法的引用，都是 git **按设计**永不追踪的树。四候选样本里一条都没有，
这正是"样本只有四个"说不出的东西。

处置：加 `UNTRACKABLE = (".git/", ".harness/")`，判为新增的第四态 `OUT_OF_INDEX`（不是 `UNRESOLVED`，
所以不报）。**没有**退回文件系统 `exists()` 兜底——那会让一个未追踪的临时文件对写它的人解析成功、
对别人失败，正是"按索引判"要防的。

## 6. 一个自造的漂移，当场钉住而不是入 bank

`paths.py` 复制了 `layer_path_check.py` 的 `TOKEN` / `PATHLIKE` / 新增行提取。**不合并**是有理由的：
`layer_path_check.py` 是纯 stdlib，而 hook 的存在性守卫只守脚本、不守它的 import——让老守卫依赖
